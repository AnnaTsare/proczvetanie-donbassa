# Процветание Донбасса

Стартовая страница проекта на русском языке. Сайт статический и подходит для GitHub Pages.

## Локальный просмотр

Откройте `index.html` в браузере. Для работы страницы сервер не требуется. При отсутствии доступа к Google Fonts используются системные шрифты.

## Публикация

Разместите файлы этой папки в корне отдельного публичного репозитория GitHub, затем в **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**. Адрес сайта будет `https://<имя-пользователя>.github.io/<имя-репозитория>/`.

## Обновление

Содержимое `index.html` пока представляет собой общую стартовую страницу. Перед добавлением имен, контактов, фотографий, статистики или новостей проверьте их точность и согласуйте публикацию.
