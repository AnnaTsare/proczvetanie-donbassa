# АНО «Процветание Донбасса»

Публикация прототипа из папки `сайт_АНО`. Сайт работает на GitHub Pages без сборки: откройте `index.html` в браузере для локального просмотра.

Публичная версия: https://annatsare.github.io/proczvetanie-donbassa/

Для обновления сайта перенесите изменения HTML, CSS, JavaScript и используемых фотографий из прототипа в этот репозиторий и отправьте их в ветку `main`. Документы Word и PowerPoint из рабочей папки не публикуются.

Внешние шрифты и изображения новостей загружаются с Google Fonts, VK и OK; их отображение зависит от доступности этих сервисов. Опрос демонстрационный: ответы не передаются и не сохраняются.
